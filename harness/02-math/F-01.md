## 1. Spesifikasi presisi
- Variabel dan domain: z ∈ (ℝ ∪ {NA})^{n×k}, n ≥ 1, k ≥ 1; setiap entri teramati **berhingga** (siklus ternormalisasi dari `normalise_cycle()` selalu berhingga; `cli_composite()` hanya menerima keluaran itu).
- Parameter: ambang cakupan m ∈ [0, 1]; q = max(1, ⌈m·k − 10⁻⁹⌉). Toleransi 10⁻⁹ melindungi dari galat titik-mengambang (mis. m = 0,6000000000000001 dan k = 5 memberi m·k = 3,0000000000000004; D4) dan sama dengan `coverage_mask()` (C5).
- Notasi: A_t = {i : z_it teramati}; c_t = 1{|A_t| ≥ q}; F = {t : |A_t| = k}; B_t = A_t ∩ A_{t−1} (t ≥ 2); Δ_it = z_it − z_{i,t−1} untuk i ∈ B_t.
- Rata-rata langsung: L_t = |A_t|^{-1} Σ_{i∈A_t} z_it bila c_t = 1, selain itu NA. Ini persis `equal_weight()` 0.1.3 (`weighted_available()` dengan bobot 1/k dan masker cakupan).
- Definisi hibrida H:
  - Bila F = ∅: H_t = L_t untuk semua t.
  - Selain itu b = max F, dan H_t = L_t untuk t ≤ b.
  - Untuk t = b+1, …, n berurutan: bila |B_t| ≥ q dan H_{t−1} terdefinisi, H_t = H_{t−1} + |B_t|^{-1} Σ_{i∈B_t} Δ_it; bila tidak, H_s = NA untuk semua s ≥ t (rantai berhenti dan tidak dimulai ulang).
- Tidak ada asumsi tanda atau besaran z (C1 tidak berlaku lagi): bentuk aditif terdefinisi untuk semua bilangan berhingga.
- Kasus batas: F = ∅; k = 1 (akibat dari definisi, bukan aturan khusus: b adalah observasi terakhir, sehingga |B_t| = 0 < q untuk t > b, dan H = L; C10); n = 1; celah cakupan sesudah b.

## 3. Bukti

**Proposisi 1.** Untuk semua t ≤ b, H_t = L_t; bila F = ∅, H = L.
*Bukti.* Langsung dari definisi. ∎

**Proposisi 2.** Bila baris n lengkap, H = L di semua t.
*Bukti.* 1. n ∈ F, jadi b = max F = n. 2. Semua t ≤ b; terapkan Proposisi 1. ∎

**Akibat 3 (kesetaraan persis dengan 0.1.3).** Bila baris n lengkap, H sama persis (bit demi bit) dengan keluaran `equal_weight()` 0.1.3, sehingga komposit ternormalisasinya juga sama persis.
*Bukti.* Implementasi mengembalikan vektor `comp` 0.1.3 tanpa diubah bila baris terakhir lengkap (Proposisi 2); normalisasi deterministik. Tidak ada penambahan konstanta, sehingga isu pembulatan revisi 1 (C6) hilang. ∎

**Proposisi 4 (kebal terhadap perubahan komposisi).** Misalkan t > b, H_{t−1} terdefinisi, |B_t| ≥ q, dan Δ_it = δ untuk semua i ∈ B_t. Maka H_t = H_{t−1} + δ, apa pun komponen yang hilang di t.
*Bukti.* |B_t|^{-1} Σ_{i∈B_t} δ = δ. ∎
Contoh lompatan yang dihindari (m = 0,5, k = 2; C9): z_{1,t−1} = z_{1,t} = 1, z_{2,t−1} = −1, komponen 2 hilang di t. L_{t−1} = 0 dan L_t = 1, padahal tidak ada komponen yang bergerak; H_t = H_{t−1}. Dengan m = 0,6, L_t = NA dan H berhenti.

**Proposisi 5 (langkah terbatas).** Untuk t > b dengan H_t terdefinisi, |H_t − H_{t−1}| ≤ max_{i∈B_t} |Δ_it|.
*Bukti.* Nilai mutlak rata-rata ≤ rata-rata nilai mutlak ≤ maksimum nilai mutlak (ketaksamaan segitiga). ∎
Proposisi ini menggantikan Proposisi 6 revisi 1 (positif) dan menjawab C1: guncangan besar di ujung seri menggerakkan H paling banyak sebesar perubahan komponen terbesar, tanpa lonjakan karena pembagian dengan level kecil.

**Proposisi 6 (cakupan setiap langkah).** Setiap H_t yang terdefinisi untuk t > b dihitung dari sedikitnya q komponen, sama dengan ambang cakupan L_t.
*Bukti.* Syarat langkah |B_t| ≥ q, dan B_t ⊆ A_t sehingga juga c_t = 1. ∎ (Menjawab C4.)

**Proposisi 7 (tafsiran pada keluaran `cli_cycles()`; D1).** Misalkan setiap kolom z teramati pada satu rentang tanpa celah (benar untuk siklus dari `cli_cycles()`, karena celah di tengah diinterpolasi), F ≠ ∅, dan b = max F < n. Maka untuk t > b: (a) A_t ⊆ A_{t−1}, sehingga B_t = A_t dan rantai terdefinisi tepat ketika c_t = 1 (selama tanggal sebelumnya terdefinisi); (b) H_t = k^{-1} Σ_{i=1}^{k} z̃_it, dengan panel isian z̃ yang didefinisikan z̃_it = z_it untuk i ∈ A_t dan z̃_it = z̃_{i,t−1} + |A_t|^{-1} Σ_{j∈A_t} Δ_jt untuk i ∉ A_t.
*Bukti.* (a) Pada b semua kolom teramati; rentang tanpa celah yang memuat b tidak dapat dimulai lagi sesudah berakhir, jadi kolom yang hilang di t > b tetap hilang sesudahnya, A_t ⊆ A_{t−1}, dan B_t = A_t ∩ A_{t−1} = A_t. Maka |B_t| ≥ q ⟺ c_t = 1. (b) Induksi pada t. Basis t = b: semua teramati, z̃_b = z_b dan H_b = L_b = k^{-1} Σ z_ib. Langkah: misalkan δ_t = |A_t|^{-1} Σ_{j∈A_t} Δ_jt. Untuk i ∈ A_t, z̃_it − z̃_{i,t−1} = Δ_it (karena A_t ⊆ A_{t−1}, z̃_{i,t−1} = z_{i,t−1}); untuk i ∉ A_t selisihnya δ_t. Rata-rata selisih atas k kolom = k^{-1}(Σ_{A_t} Δ_it + (k − |A_t|) δ_t) = k^{-1}(|A_t| δ_t + (k − |A_t|) δ_t) = δ_t. Jadi k^{-1} Σ z̃_it = H_{t−1} + δ_t = H_t. ∎
Di luar kondisi rentang tanpa celah (panggilan langsung `aggregate_components()` dengan pola NA buatan), rantai tetap terdefinisi menurut §1, tetapi tafsiran (b) tidak berlaku; kasus ini tidak dapat terjadi melalui `cli_composite()`, `cli_build()`, atau GUI.

## 6. Algoritma
- Prasyarat: z matriks numerik berhingga atau NA; m ∈ [0, 1]. Pascasyarat: vektor panjang n.
- Penjaga dalam pseudokode (C8): bila F = ∅ kembalikan L (tidak memanggil `max()` pada himpunan kosong); bila b = n kembalikan L.
- Loop t = b+1…n dengan invarian "H_{t−1} terdefinisi, atau loop sudah berhenti". Terminasi: paling banyak n − b langkah.
- Kompleksitas: waktu O(nk), memori O(n).
- Stabilitas (C7): hanya penjumlahan dan pengurangan; galat absolut bertambah paling banyak O((n − b)·k·ε·max|z|) (D4). Tidak ada pembagian dengan nilai data.

## 7. Bentuk implementasi
```
comp <- weighted_available(z, 1/k); comp[!coverage_mask(z, m)] <- NA
full <- which(complete.cases(z)); if (length(full) == 0) return(comp)
b <- max(full); if (b == n) return(comp)
q <- max(1, ceiling(m * k - 1e-9)); out <- comp; out[(b+1):n] <- NA
obs <- !is.na(z)
for (t in (b+1):n) { both <- obs[t, ] & obs[t-1, ]
  if (sum(both) < q || is.na(out[t-1])) break
  out[t] <- out[t-1] + mean(z[t, both] - z[t-1, both]) }
```
Setara dengan §1: `weighted_available` dengan bobot sama = rerata atas A_t; `break` = rantai berhenti (sisa sudah NA).
