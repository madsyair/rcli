# F-10 — Rantai rata-rata laju log dengan pembalikan resiprokal

Class: B
Status: CITED-VERIFIED (bentuk rantai); pilihan log dan resiprokal NUMERICALLY-SUPPORTED terhadap data OECD
Dipakai oleh: FR-014 (`oecd_aggregate(growth = "log")`, metode `aggregate_components()` untuk `OecdAggregate`)

## 1. Spesifikasi presisi
- Masukan: matriks siklus ternormalisasi z (T × m, boleh NA), tanda s_i ∈ {1, −1} (−1 bila komponen sudah dibalik oleh `invert_cycle()`, yaitu z_i = −z_i^asal), ambang cakupan c ∈ (0, 1].
- Indeks komponen: L_{it} = 100 + z_{it} bila s_i = 1; L_{it} = 100² / (100 − z_{it}) bila s_i = −1.
- Laju: g_t = rata-rata_{i tersedia di t dan t−1} [ln L_{it} − ln L_{i,t−1}].
- Rantai: I_t = I_{t−1} · exp(g_t) bila I_{t−1} dan g_t ada dan cakupan(t) ≥ c; awal rantai I_t = rata-rata_i L_{it}; cakupan(t) < c → NA.
- Keluaran: I, kemudian dinormalisasi ulang oleh `cli_composite()`.

## 2. Sumber
- Gyomai dan Guidetti (2012, hlm. 9): "The aggregation is done by averaging the growth rates of each component indicator. Then, the average growth rates are chained to form the final indicator"; komponen kontra-siklis dibalik, caranya tidak dirinci.
- Validasi dengan data OECD Indonesia (`data-raw/oecd_idn_validate.R`, bagian C1): laju aritmetika + pembalikan tanda r = 0,99839; laju log + pembalikan resiprokal r = 0,99985 terhadap CLI ternormalisasi terbitan OECD.

## 3. Turunan ulang
1. Untuk s_i = −1: z_i = −z_i^asal, sehingga 100 − z_i = 100 + z_i^asal = indeks asal A_i. L_i = 100²/A_i, sehingga ln L_{it} − ln L_{i,t−1} = −(ln A_{it} − ln A_{i,t−1}): pembalikan resiprokal tepat membalik tanda laju log.
2. Untuk z kecil, ln(1 + z/100) ≈ z/100, sehingga laju log ≈ laju aritmetika ≈ Δz/100; kedua rumus berbeda pada orde kedua, yang terbesar pada ayunan besar (1997–1998, 2020).
3. Bila semua komponen sama (z_i = z, s_i = 1), I_t = 100 + z_t untuk semua t (rantai log dari satu indeks kembali ke indeks itu).

## 4. Verifikasi simbolik
Langkah 1 dan 3 adalah identitas logaritma; diperiksa numerik di uji.

## 5. Verifikasi numerik
- `test-oecd.R`: rantai log sama dengan perhitungan langsung exp(kumulatif rata-rata Δln L) (galat < 1e-10); komponen identik mengembalikan 100 + z; komponen terbalik dengan resiprokal memberi laju negatif seri asal; replikasi CLI Indonesia r > 0,9995.
