# F-06 — Uji HAC Bartlett *fixed-b* untuk konkordansi dan arah perubahan

## 1. Spesifikasi presisi
- Masukan: y, x ∈ ℝⁿ tanpa NA, n ≥ 10, var(x) > 0, var(y) > 0 (selain itu nilai p NA).
- Regresi y_t = α + βx_t + u_t dengan OLS; X = [1, x]; û sisaan; v_t = X_t·û_t (vektor 2).
- Varians HAC Bartlett dengan *bandwidth* M = b·n, b = 0,3:
  Ω̂ = Γ̂_0 + Σ_{l=1}^{⌈M⌉−1} (1 − l/M)(Γ̂_l + Γ̂_lᵀ), dengan Γ̂_l = Σ_{t=l+1}^{n} v_t v_{t−l}ᵀ;
  V̂ = (XᵀX)⁻¹ Ω̂ (XᵀX)⁻¹.
- Statistik t = β̂ / √V̂_22.
- Nilai p satu sisi (H1: β > 0): p = P(T > t), dengan T berdistribusi limit *fixed-b* untuk b = 0,3.
  - Nilainya diambil dari tabel `fixed_b_null` (305 kuantil |T| dari 400 000 tarikan) dengan interpolasi linear.
  - Simetris: p(−t) = 1 − p(t).
  - Untuk t di atas kuantil terbesar, p = 10⁻⁴ (batas bawah tabel).
- Kecocokan persis (sisaan nol, V̂_22 = 0) dengan β̂ ≠ 0 memberi p = 10⁻⁴ (β̂ > 0) atau 1 − 10⁻⁴ (β̂ < 0). Kasus ini ditangani eksplisit dan tidak bergantung pada galat pembulatan (C8).
- Pemakaian:
  - konkordansi: y = status fase seri acuan (1 ekspansi, 0 kontraksi), x = status fase kandidat yang digeser `shift` periode (Harding dan Pagan 2006);
  - arah: y = 1{Δ acuan_t > 0}, x = 1{Δ komposit_{t−h} > 0}, tanpa periode dengan perubahan nol (bentuk regresi Pesaran dan Timmermann 2009).

## 2. Sumber
- Kiefer, N. M. dan Vogelsang, T. J. (2005). A new asymptotic theory for heteroskedasticity-autocorrelation robust tests. *Econometric Theory*, 21(6), 1130–1164: distribusi limit t dengan *bandwidth* M = bT yang tetap proporsional; limitnya tidak bergantung pada parameter gangguan dan pada regresor; nilai kritis untuk kernel Bartlett (permukaan respons polinomial dalam b).
- Harding, D. dan Pagan, A. (2006). Synchronization of cycles. *Journal of Econometrics*, 132(1), 59–79: uji konkordansi sebagai uji kemiringan regresi status pada status dengan galat baku HAC.
- Pesaran, M. H. dan Timmermann, A. (2009). Testing dependence among serially correlated multicategory variables. *JASA*, 104(485), 325–337: uji arah sebagai uji kemiringan regresi indikator kategori. Untuk korelasi serial, mereka memakai regresi yang diperluas secara dinamis dengan lag variabel terikat, bukan HAC.
- Kelas B: kedua statistik (regresi status Harding–Pagan dan regresi arah Pesaran–Timmermann) dan varians *fixed-b* sudah ada di literatur. Yang menjadi pilihan paket (C3) adalah:
  - gabungan regresi statis dengan HAC *fixed-b* sebagai ganti perluasan dinamis PT 2009 atau HAC konvensional Harding–Pagan;
  - pilihan b;
  - tabel nilai p tersimulasi.
  Pilihan itu diverifikasi secara numerik di §5.

## 3. Turunan ulang
1. Di bawah H0 (x dan y independen, keduanya stasioner dan *mixing*), β = 0 dan v_t = X_t u_t memenuhi FCLT. Asumsi Kiefer dan Vogelsang (2005) atas regresor juga terpenuhi (C2): T⁻¹Σ_{t≤rT} X_tX_tᵀ → rQ secara seragam di r ∈ [0, 1], dengan Q definit positif. Syarat ini berlaku bagi status fase biner yang stasioner, tanpa tren atau patahan. Dengan M = bn, Kiefer dan Vogelsang (2005) menunjukkan t ⇒ W(1)/√Q_b, dengan Q_b fungsional jembatan Brown yang hanya bergantung pada kernel dan b. Hasil umum untuk regresi linear ada pada teorema utama makalah itu; rinciannya di lampiran.
2. Karena limitnya bebas parameter, ia dapat disimulasikan dengan model lokasi y_t = μ + ε_t, ε iid N(0, 1), n besar (`data-raw/fixed_b_table.R`, n = 1000, 400 000 ulangan; autokovarians lewat FFT).
3. Limitnya simetris di sekitar 0, sehingga P(T > t) = ½P(|T| > t) untuk t ≥ 0. Alasannya: W(1) simetris, dan B(r) = W(r) − rW(1) independen dari W(1) (keduanya Gauss dengan kovarians r − r = 0), sehingga Q_b independen dari W(1). Tabel memakai |T| untuk menggandakan presisi.
4. Pilihan b (CSV studi "size-markov"; status Markov independen, 2000 ulangan; nilai kritis permukaan respons Kiefer–Vogelsang untuk b selain tabel):
   - n = 360, ganti 1/12: b = 0,1/0,2/0,3/0,5 → 6,5%/6,6%/6,6%/6,7%;
   - n = 360, ganti 1/24: b = 0,1/0,2/0,3/0,5 → 7,9%/7,6%/7,6%/7,8%;
   - n = 120, ganti 1/24: b = 0,1/0,2/0,3/0,5 → 14,2%/11,8%/11,0%/10,7%.

   Untuk n besar, b hampir tidak berpengaruh. Untuk n kecil, b kecil paling longgar dan b ≥ 0,3 sebanding, sedangkan daya turun ketika b naik (Kiefer dan Vogelsang 2005). b = 0,3 adalah kompromi.
5. Bandwidth Newey–West bawaan 0.5.1, ⌊4(n/100)^{2/9}⌋ = 5 untuk n = 360, terlalu kecil untuk status yang berganti kira-kira setiap 24 bulan (ρ₁ ≈ 0,9). Inilah sebab penolakan 27–31%.

- Implementasi sesuai dengan §1:
  - lag 1, …, ⌈M⌉ − 1 dengan bobot 1 − l/M (untuk M tak bulat, lag ⌊M⌋ masih
