## 1. Spesifikasi presisi
- Variabel: seri tertransformasi x_1,…,x_n (tanpa nilai hilang), d_t = x_t − x_{t−1}, t = 2,…,n.
- Model: d_t − μ = Σ_{j=1}^{p} φ_j (d_{t−j} − μ) + ε_t, ε_t white noise varians σ²; μ ditaksir dengan rerata sampel d̄.
- Parameter: orde p ∈ {0,…,p_max} dipilih dengan AIC; φ ditaksir dengan persamaan Yule-Walker (Levinson-Durbin) seperti `stats::ar(method = "yule-walker")`.
- Keluaran: prakiraan x̂_{n+s} = x_n + Σ_{u=1}^{s} d̂_{n+u}, s = 1,…,h, dengan d̂_{n+u} prediktor linear terbaik rekursif: d̂_{n+u} = μ̂ + Σ_j φ̂_j (d̃_{n+u−j} − μ̂), d̃ = nilai teramati atau prakiraan.
- Kasus batas: varians d nol atau sebatas galat pembulatan (var(d) ≤ (√ε · max|d|)², mis. tren linear 0,01·t) → garis lurus x_n + s·d̄ tanpa memanggil `ar()`; begitu juga bila `ar()` gagal atau prakiraannya tak berhingga. Orde dibatasi p ≤ min(p_max, ⌊10 log10 m⌋, m − 2) dengan m = n − 1 banyaknya perubahan; Yule-Walker selalu memberi model stasioner (Brockwell & Davis 1991), sehingga prakiraan terbatas.
- h bawaan = frekuensi (12 atau 4); p_max bawaan = frekuensi. Masukan: `ts` tanpa NA dengan n ≥ 3, selain itu `rcli_error_argument`.

## 2. Sumber
- Brockwell, P. J. dan Davis, R. A. (1991). *Time Series: Theory and Methods*, edisi 2. Springer, New York: estimator Yule-Walker untuk AR, algoritma Durbin-Levinson, dan prediktor linear terbaik proses AR (rujukan dokumentasi `?stats::ar` dan `?predict.ar`).
- Akaike, H. (1974). A new look at the statistical model identification. *IEEE Transactions on Automatic Control*, 19(6), 716–723 (AIC untuk memilih orde).
- Gyomai dan Guidetti (2012, hlm. 7): OECD memperpanjang seri dengan prakiraan jangka pendek sebelum penyaring HP; Kaiser dan Maravall (2001) untuk manfaatnya pada revisi ujung.

## 3. Turunan ulang
1. x_{n+s} = x_n + Σ_{u=1}^{s} d_{n+u} (identitas jumlah teleskopik), sehingga prakiraan x adalah x_n ditambah jumlah prakiraan d; karena ekspektasi linear, E[x_{n+s} | ℱ_n] = x_n + Σ E[d_{n+u} | ℱ_n].
2. Untuk AR(p) stasioner, E[d_{n+u} | ℱ_n] memenuhi rekursi d̂_{n+u} − μ = Σ φ_j (d̂_{n+u−j} − μ) dengan d̂_{n+u−j} = d_{n+u−j} bila u − j ≤ 0 (Brockwell dan Davis 1991). Ini persis `predict.ar`.
3. Bila semua d_t sama (= δ), rerata d̄ = δ dan semua deviasi nol; implementasi langsung memberi x̂_{n+s} = x_n + sδ: tren linear diteruskan tanpa galat (cabang garis lurus, tanpa `ar()`).

## 4. Verifikasi simbolik
Kelas A: tidak wajib. Identitas teleskopik langkah 1 diperiksa numerik.

## 5. Verifikasi numerik
- Skrip: `scripts/F-02_numeric.R`.
- Uji: (a) tren linear murni → galat ≤ 1e-8; (b) AR(1) pada perubahan φ = 0,6, n = 600: prakiraan paket = x_n + cumsum(predict(ar(d))) (≤ 1e-10); (c) prakiraan 1 langkah sama dengan rumus manual μ̂ + φ̂(d_n − μ̂) untuk model orde 1 (≤ 1e-10); (d) φ̂ dekat 0,6 (|galat| < 0,1).

## 6. Algoritma
- Prasyarat: n ≥ 3, tanpa NA. Pascasyarat: vektor panjang h, berhingga.
- Kompleksitas: Durbin-Levinson O(n p_max + p_max²); prakiraan O(h p).
- Stabilitas: model Yule-Walker stasioner, akar di luar lingkaran satuan; prakiraan d̂ meluruh ke μ̂.

## 7. Bentuk implementasi
`ar_forecast()` memanggil `stats::ar(d, aic = TRUE, order.max = p, method = "yule-walker")` dan `predict(fit, n.ahead = h)$pred`; hasil `x_n + cumsum(·)`. Bila var(d) sebatas galat pembulatan, `ar()` gagal, atau prakiraan tak berhingga: `x_n + mean(d) * seq_len(h)`.
