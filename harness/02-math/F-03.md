# F-03 — Penyaring HP dengan faktorisasi LDLᵀ pita (O(n))

Class: A
Status: CITED-VERIFIED
Dipakai oleh: FR-004 (dan semua jalur `hp_filter()`, `hp_double_filter()`, `cli_presentation()`)

## 1. Spesifikasi presisi
- Masukan: x ∈ ℝⁿ tanpa nilai hilang, n ≥ 4; λ ≥ 0.
- Tren HP: τ = argmin_τ Σ (x_t − τ_t)² + λ Σ (Δ²τ_t)², sehingga (I + λ D₂ᵀD₂) τ = x, dengan D₂ matriks selisih kedua berukuran (n − 2) × n.
- A = I + λ D₂ᵀD₂ simetris pentadiagonal:
  - diagonal 1 + λ·(1, 5, 6, …, 6, 5, 1);
  - subdiagonal pertama λ·(−2, −4, …, −4, −2);
  - subdiagonal kedua λ·(1, …, 1).
- Keluaran: τ (vektor panjang n). Siklus HP = x − τ; penyaring HP ganda OECD menerapkan τ dua kali.
- Kasus batas:
  - λ = 0 → A = I, τ = x;
  - n < 4 → galat `rcli_error_short_series` (tidak berubah);
  - x linear (x_t = a + bt) → τ = x, karena D₂x = 0.

## 2. Sumber
- Hodrick, R. J. dan Prescott, E. C. (1997). Postwar U.S. business cycles: an empirical investigation. *Journal of Money, Credit and Banking*, 29(1), 1–16: definisi τ sebagai penyelesaian sistem linear di atas.
- Golub, G. H. dan Van Loan, C. F. (2013). *Matrix Computations*, edisi 4, Johns Hopkins University Press, bagian 4.1–4.3: faktorisasi LDLᵀ matriks simetris definit positif, keberadaan dan ketunggalannya dengan pivot positif, serta pelestarian lebar pita (faktor L dari matriks pita berlebar p juga berlebar p; biaya O(np²)).
- Higham, N. J. (2002). *Accuracy and Stability of Numerical Algorithms*, edisi 2, SIAM, bab 10: faktorisasi Cholesky/LDLᵀ matriks SPD stabil mundur tanpa pivoting.
- Kim, S.-J., Koh, K., Boyd, S. dan Gorinevsky, D. (2009). ℓ1 trend filtering. *SIAM Review*, 51(2), 339–360: penyaring HP dapat dihitung dalam O(n) karena matriksnya berpita.

## 3. Turunan ulang
1. Syarat orde pertama fungsi tujuan kuadrat: −2(x − τ) + 2λD₂ᵀD₂τ = 0 ⇒ Aτ = x.
2. A SPD untuk λ ≥ 0: vᵀAv = ‖v‖² + λ‖D₂v‖² ≥ ‖v‖² > 0 untuk v ≠ 0. Maka A = LDLᵀ tunggal dengan L segitiga bawah satuan dan d_i > 0 (Golub dan Van Loan 2013, §4.1–4.2).
3. Karena A berpita bawah 2, L juga berpita bawah 2 (§4.3). Tulis l1_i = L_{i,i−1}, l2_i = L_{i,i−2}. Menyamakan entri (i,i), (i+1,i), (i+2,i) dari LDLᵀ dengan A memberi:
   - d_i = a0_i − l1_i² d_{i−1} − l2_i² d_{i−2};
   - l1_{i+1} = (a1_i − l2_{i+1} l1_i d_{i−1}) / d_i;
   - l2_{i+2} = a2_i / d_i.

   Suku dengan indeks < 1 bernilai nol.
4. Penyelesaian: Lw = x (maju), z = w / d, Lᵀτ = z (mundur), masing-masing O(n).
5. Invarian: D₂·1 = 0 dan D₂·t = 0 ⇒ 1ᵀA = 1ᵀ dan tᵀA = tᵀ ⇒ Σ τ_t = Σ x_t dan Σ t τ_t = Σ t x_t (tren HP mempertahankan rerata dan kemiringan kuadrat terkecil).
6. Stabilitas: dengan aritmetika berpresisi u, solusi terhitung memenuhi (A + ΔA)τ̂ = x dengan ‖ΔA‖ ≤ c·u·‖A‖ untuk konstanta c kecil yang bergantung pada lebar pita (Higham 2002, bab 10). Galat maju relatif ≲ κ(A)·c·u dengan κ(A) ≤ 1 + 16λ, karena nilai eigen D₂ᵀD₂ terletak di [0, 16). Untuk λ = 133 107,9 (OECD bulanan): κ ≤ 2,1·10⁶, galat ≲ 10⁻⁹ relatif.

## 6. Algoritma
- Prasyarat: n ≥ 4, x berhingga, λ ≥ 0 berhingga. Pascasyarat: τ berhingga, panjang n.
- Kebenaran: setiap iterasi i dari faktorisasi hanya memakai d_{i−1}, d_{i−2}, l1_i, l2_i, l2_{i+1} yang sudah dihitung pada iterasi sebelumnya (invarian: sesudah iterasi i, d_{1..i}, l1_{2..i+1}, l2_{3..i+2} benar). Loop berhingga (n iterasi), jadi berhenti.
- Kompleksitas: waktu O(n) (tiga loop berpanjang n dengan kerja konstan), memori O(n). Sebelumnya waktu O(n³) dan memori O(n²).
- Stabilitas: lihat langkah 6; tanpa pivoting karena A SPD.
