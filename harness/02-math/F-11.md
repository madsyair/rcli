# F-11 — Faktor amplitudo rasio simpangan baku

Class: B
Status: CITED-VERIFIED (prinsip penyesuaian amplitudo); ukuran sd NUMERICALLY-SUPPORTED terhadap data OECD
Dipakai oleh: FR-014 (`cli_spec(amplitude = "sd")`, `reference_amplitude()`)

## 1. Spesifikasi presisi
- Masukan: siklus acuan r_t dalam persen deviasi dari tren (bentuk nilai: 100 × siklus log, atau 100 × siklus / rata-rata |level| untuk seri tanpa log; bentuk laju: poin persen), siklus komposit ternormalisasi c_t.
- "mad" (0.7.0): a = MAD(r) atas seluruh r yang ada (c sudah ber-MAD 1).
- "sd": a = sd(r_t) / sd(c_t) atas t yang r_t dan c_t sama-sama ada; bila irisan < 3 observasi, a = sd(r)/sd(c) atas masing-masing rentang.
- Indeks: 100 + a · c_t.

## 2. Sumber
- Gyomai dan Guidetti (2012, hlm. 9): "The amplitude adjusted CLI rescales this 'averaged' CLI to match the amplitudes of the de-trended reference series"; glosarium OECD: amplitudo siklus CLI "on average agrees" dengan seri acuan. Ukurannya tidak disebut.
- Validasi data OECD Indonesia (bagian C2): CLI *amplitude adjusted* = 100 + 1,71288 (CLI ternormalisasi − 100) (R² = 0,99999); rasio sd pada rentang bersama 1,704–1,712; rasio MAD 1,427.

## 3. Turunan ulang
Dengan a = sd(r)/sd(c), sd(a·c) = sd(r): indeks dan acuan berayun dengan simpangan baku sama. Dengan "mad", MAD(a·c) = MAD(r).

## 4. Verifikasi simbolik
Kelas B, identitas skala; tidak perlu CAS.

## 5. Verifikasi numerik
- `test-oecd.R`: sd(indeks − 100) = sd(acuan) pada rentang bersama (galat < 1e-10); bawaan "mad" sama dengan 0.7.0; indeks AA Indonesia berbeda < 0,1 poin dari terbitan OECD.
