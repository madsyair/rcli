# F-09 — Penghalus HP (tren HP berperiode potong pendek)

Class: A
Status: CITED-VERIFIED
Dipakai oleh: FR-013 (`hp_smoother()`, metode `extract_cycle()` untuk `HPSmoother`)

## 1. Spesifikasi presisi
- Masukan: x ∈ ℝⁿ tanpa nilai hilang, n ≥ 4; periode potong p > 2 (bawaan p = f, satu tahun).
- λ(p) = [4 (1 − cos(2π/p))²]⁻¹ (`hp_lambda()`, F-03); λ(4) = 0,25, λ(12) ≈ 13,93.
- Keluaran: τ = tren HP dengan λ(p), dihitung dengan penyelesai O(n) F-03. Tidak ada pembuangan tren: keluaran adalah komponen berfrekuensi rendah dari x (periode di atas p dipertahankan).
- Kasus batas: x konstan → τ = x; x linear → τ = x (D₂x = 0); p ≤ 2 atau tak hingga → `rcli_error_argument`.

## 2. Sumber
- Hodrick, R. J. dan Prescott, E. C. (1997): definisi tren HP.
- F-03 (penyelesai pita dan λ(p) dengan gain ½ pada periode p).
- Gyomai dan Guidetti (2012): tahap kedua HP ganda OECD menghaluskan siklus dengan HP berperiode potong satu tahun. `hp_smoother()` adalah tahap kedua itu saja, dipakai bila seri sudah tidak bertren (laju atau percepatan).

## 3. Turunan ulang
1. HP ganda OECD: c = HP_{p_s}(x − HP_{p_t}(x)). Untuk seri tanpa tren (laju pertumbuhan stasioner), tahap pertama tidak diperlukan; tahap kedua saja memberi HP_{p_s}(x).
2. Gain penghalus pada frekuensi ω: G(ω) = 1 / (1 + 4λ(1 − cos ω)²); G(2π/p) = ½ dengan λ = λ(p) (F-03).

## 4. Verifikasi simbolik
Kelas A: tidak wajib; G(2π/p) = ½ diperiksa langsung dari definisi λ(p).

## 5. Verifikasi numerik
- `test-cycle-form.R`: `extract_cycle(hp_smoother(4), x)` sama dengan x − `extract_cycle(hp_filter(hp_lambda(4)), x)` (galat < 1e-10); seri konstan dan linear tidak berubah (galat < 1e-8); sama dengan `PenghalusHP` kajian PKRT.
